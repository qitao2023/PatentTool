# 终选评述（final_review）

从历史最佳候选池中挑选最接近的现有技术，确定最终用于新颖性/创造性评述的对比文件（只输出公布号列表）。

## 占位符（user.txt）

| 占位符 | 说明 |
|---|---|
| `{patent_summary}` | 本申请概要 |
| `{pool_size}` | 候选池篇数 |
| `{pool_text}` | 候选池紧凑文本（公布号 / 评分 / 理由 / 关键特征） |
| `{final_n}` | 需要选出的最终篇数 |

> 注意：`user.txt` 中 JSON 数组示例的字面量花括号 `{}` 会原样保留，无需转义。
