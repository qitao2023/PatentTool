## 第一步：识别专利类型

在生成检索式之前，先判断本申请属于以下哪种类型，不同类型采用不同的检索侧重点：

### 类型1：器件结构专利（如 FinFET、IGBT、3D NAND 单元、图像传感器像素）
- 检索重点：结构特征 + 材料 + 功能效果
- IPC 集中在：H01L 29/、H10B、H01L 27/、H01L 31/

### 类型2：制造工艺专利（如 ALD 沉积方法、选择性刻蚀、离子注入、CMP）
- 检索重点：工艺步骤 + 工艺参数 + 适用器件类型
- IPC 集中在：H01L 21/、C23C 16/、G03F

### 类型3：封装/互连专利（如 TSV、3D堆叠、Fan-out、Hybrid Bonding）
- 检索重点：封装结构 + 互连方式 + 材料界面
- IPC 集中在：H01L 23/、H01L 25/、H01L 21/768

### 类型4：材料/介质专利（如 high-k 介质、low-k 材料、光刻胶、CMP 研磨液）
- 检索重点：材料组成 + 制备方法 + 应用场景
- IPC 集中在：C09K、C08L、H01L 21/02

### 类型5：设备/装置专利（如 PVD 腔体、静电卡盘、光刻机部件）
- 检索重点：设备结构 + 功能部件 + 工艺效果

### 类型6：MEMS/传感器专利（如加速度计、陀螺仪、压力传感器）
- 检索重点：机械结构 + 牺牲层工艺 + 敏感材料
- IPC 集中在：B81B、B81C、G01P、G01L

### 类型7：功率器件专利（如 IGBT、SiC MOSFET、GaN HEMT、超结）
- 检索重点：耐压结构 + 宽禁带材料 + 导通/开关特性
- IPC 集中在：H01L 29/16、H01L 29/20、H01L 29/78、H01L 29/739

### 类型8：光电器件专利（如 LED、激光器、光电探测器、太阳能电池）
- 检索重点：有源层结构 + 外延生长 + 光提取/转换效率
- IPC 集中在：H01L 33/、H01L 31/、H01S 5/

### 混合类型
多数半导体专利是多种类型的组合（如"FinFET + 其制造方法"），此时需综合多种策略。

## 核心检索方法论

### 策略1：IPC 驱动
第1个检索式始终是"IPC + 核心关键词"，保证最宽泛的查全率。
将 IPC 分类号作为关键词，如 `"H01L 29/66" OR "H01L 21/336"`

### 策略2：功能性限定破解
对权利要求中的功能性限定（如"用于降低应力的层"、"用于提高击穿电压的结构"），
必须反推 2-3 种可能的具体实现方案，分别为每种方案构建检索式。
这与半导体审查的"means-plus-function"破解直接对应。

### 策略3：洋葱分层（A+B+C+D 逐层收窄）
将技术方案拆解为：
- A = 基础器件/结构类型
- B = 关键部分（栅极/沟道/隔离/接触/有源层等）
- C = 形成方法/工艺条件
- D = 特殊形状/参数/尺寸

生成 A+B（宽）→ A+B+C（中）→ A+B+C+D（最准）的逐层检索式。
同时做 A+B+D（旁路，忽略工艺限制）和 C+A（方法跨器件）的补充检索。

### 策略4：材料/结构/参数三维扩展
- **结构维度**：FinFET、GAA、nanosheet、nanowire、planar、trench、stacked、vertical、super-junction、floating gate、charge trap
- **材料维度**：Si、SiGe、Ge、GaN、SiC、GaAs、InP、InGaAs、Ⅲ-Ⅴ族；SiO2、SiN、SiON、SiCN、SiCO、high-k(HfO2/Al2O3/ZrO2/La2O3/HfSiO/HfZrO)、low-k(SiCOH/porous)、金属(TiN/TaN/W/Co/Mo/Ru)
- **参数维度**：膜厚(Å~nm)、掺杂浓度(atoms/cm³)、退火温度/时间/气氛、宽深比、CD/线宽、接触电阻、击穿电压、阈值电压

### 策略5：中日英三语覆盖

核心关键词必须中英日三语扩展（日文帮助覆盖日本申请人的文献）。

## PATENTSCOPE 检索语法限制

- 仅支持关键词 + AND/OR/NOT 运算符
- 精确短语用英文双引号："gate dielectric"
- 通配符：* (多字符) ？(单字符)
- 不支持 FP:() 字段限定，不支持 NEAR/ADJ 临近算符
- IPC 分类号作为普通关键词使用，如 "H01L-29" 或 "H01L 29/66"

## 检索式构建原则

1. **全部精准**：所有检索式都应精准反映权利要求的技术特征，不做宽泛兜底。宽泛兜底检索式由任务提示词统一要求生成，零结果时系统自动启用
2. **先识后搜**：先判断专利类型（器件/工艺/封装/材料/设备/MEMS/功率/光电），再选择检索策略
3. **功能性破解**：对功能性限定反推具体实现方案
4. **洋葱分层**：A+B → A+B+C → A+B+C+D 逐层收窄，同时做旁路检索
5. **三语覆盖**：核心词中英日三语扩展
6. **越简单越好**：每个检索式 ≤5 个关键词，≤3 个运算符
7. **混合类型综合处理**：如"器件+工艺"混合型，各维度都要覆盖
